## 2. 当前执行规则

| 项目 | 当前处理 | 确认边界 |
|---|---|---|
| 字段 | 校验五列；ID 保留字符串并要求全数字 | 全数字限制仅适合本批资料，不能泛化到所有平台 ID |
| 时间 | 按年月日与小时解析，不转换时区 | 业务时区、采集完整性待确认 |
| 行为 | 暂按 1 浏览、2 收藏、3 加购、4 购买 | 来自项目说明，须确认与 CSV 字典一致 |
| 去重 | 用户、商品、行为、小时四元组全局合并 | 定义的是小时内是否发生，不是精确次数 |
| 类目 | 同键按类目排序保留；另查商品多类目 | 本批无冲突；未来冲突需重新设计，不据排序认定正确类目 |
| 异常值 | 时间/ID/行为码非法记录排除；不因活跃高或大促峰值直接删除 | 无订单金额，不能做金额异常判断 |
| 留存 | 原 CSV 保留；派生 Parquet 与数据库留本地 | 可以重新按确认后的口径处理 |

## 3. 去重敏感性对照

| 行为 | 去重前有效记录 | 去重后记录 | 合并记录 | 合并比例 |

| 浏览 | 11,550,581 | 5,535,879 | 6,014,702 | 52.07% |
| 收藏 | 242,556 | 239,472 | 3,084 | 1.27% |
| 加购 | 343,564 | 331,350 | 12,214 | 3.56% |
| 购买 | 120,205 | 106,678 | 13,527 | 11.25% |

来源：[去重对照](../reports/dedup_sensitivity.csv)。总体合并比例 49.31%，浏览受影响最大。去重前购买事件占全部记录约 0.98%，去重后约 1.72%；分母受影响不同，不能把这一变化解释为业务转化提升。

在当前无效行 0、各商品类目唯一的条件下，四元组合并不改变用户集合及各小时/各日是否有某类行为，因此 DAU、购买用户数比事件频次更稳定。跨小时先后仍可观察，同小时先后无法恢复。购买记录不是订单数。
