# 类别权重对照、验证曲线与用户回访

日期：2026-11-23。均为离线探索结果，不构成最终业务结论。

## 一、固定 LR 的类别权重对照

此前训练使用 balanced 类别权重，但没有独立验证其影响。本次只将 LR24 的类别权重改为 None，保留同一训练窗口、24 项特征、log1p 变换、训练集标准化、C=1、lbfgs、最多 500 次迭代及随机种子 42。未进行过采样或欠采样。拟合前保存协议，收敛警告作为错误处理。

训练候选 1,030,893 对，其中正例 2,735 对；验证候选 1,061,515 对，其中正例 2,525 对。每个模型的分类阈值均按既定验证 F1 规则选取；各自阈值指标不代表相同预测预算。

| 验证指标 | LR24 balanced | LR24 未加权 | HGB31 原基线参考 |
|---|---:|---:|---:|
| AP | 0.027830 | 0.034241 | 0.039328 |
| ROC AUC | 0.883743 | 0.877672 | 0.881827 |
| 精确率 | 4.0806% | 5.8088% | 7.2530% |
| 召回率 | 20.0396% | 18.7723% | 14.5347% |
| F1 | 0.067806 | 0.088723 | 0.096770 |
| 验证 F1 阈值 | 0.948675 | 0.038171 | 0.937109 |
| 全局 Top-5,060 命中 | 241 | 312 | 367 |
| 全局 Top-12,400 命中 | 506 | 616 | 654 |

在本窗口上，未加权 LR 的 AP、固定预算命中优于原加权 LR，ROC AUC 则较低。不能仅凭“做了不平衡处理”断言模型更好，也不能把这次结果推广到其他时间或线上业务。HGB31 仅为原存档模型参考，本次未检验其加权与不加权差异。

本次没有访问测试样本、没有替换基线、没有继续调参。验证集已用于多次探索，无显著性检验或新的独立测试结论。

## 二、可交互曲线

重新加载本地 LR24、HGB31 原模型，核对所有验证指标与存档一致，再导出 PR、ROC 及阈值汇总。新增未加权 LR 作为独立研究模型展示。

- 每条 PR / ROC 曲线最多 400 个有序展示点，保留两端；AP / AUC 使用全部预测计算，不能对抽点图求面积替代指标。
- PR 支持 0—12% 精确率放大视图，可切回完整范围。
- 阈值网格包含等距阈值、分数分位点和各自验证 F1 阈值，不代表业务投放阈值。
- 全局预算按分数降序取前 K；同分按用户、商品编号稳定排序，仅输出汇总，不公开标识或单条预测。
- 类别加权模型分数未经过概率校准；不同模型分数不能直接解释为相同购买概率。

## 三、首次观测队列回访

用户在本数据中的首次出现日作为队列日；D1 / D3 / D7 分别统计恰好相隔 1 / 3 / 7 个自然日有任意交互的用户，同日重复事件不重复计人数。

| 指标 | 成熟队列人数 | 当日回访人数 | 回访率 |
|---|---:|---:|---:|
| D1 | 9,988 | 7,082 | 70.9051% |
| D3 | 9,971 | 6,662 | 66.8138% |
| D7 | 9,904 | 6,611 | 66.7508% |

不足相应后续观察天数的队列，回访人数与比率留空，不填零。不同 Dn 的分母可能不同。首观测不等于注册，观测期开始前的用户历史未知，且采样完整性未确认；这些数值不能称为新用户注册留存率，也不能据此证明运营效果。
