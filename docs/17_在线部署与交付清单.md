## 部署方案

使用 Streamlit Community Cloud，从当前公开 GitHub 仓库构建。在线应用只读取仓库中的汇总包、特征字典、模型指标和已有结果图，不需要原始 CSV、用户级数据、模型文件或本地数据库。

官方依据：[部署应用](https://docs.streamlit.io/deploy/streamlit-community-cloud/deploy-your-app/deploy)、[依赖配置](https://docs.streamlit.io/deploy/streamlit-community-cloud/deploy-your-app/app-dependencies)。

| 配置项 | 值 |
|---|---|
| Repository | sshwdh/douyin-user-behavior-analysis |
| Branch | main |
| Main file path | scripts/run_dashboard.py |
| Python | 3.12 |
| 依赖入口 | 根目录 requirements.txt，安装本项目 dashboard 依赖 |
| 页面主题 | .streamlit/config.toml |
| Secrets | 当前不需要 |

本地复核：在 Python 3.12 环境运行 `python -m pip install -r requirements.txt`，再运行 `python -m streamlit run scripts/run_dashboard.py`。中文路径在 ASCII 区域设置下需使用 `LANG=en_US.UTF-8 LC_ALL=en_US.UTF-8`。

## 实际发布步骤

1. 在 Streamlit Community Cloud 登录用户自己的账户并连接相应 GitHub 账号。若出现新账号条款或新增 GitHub 授权，由用户确认后完成。
2. 按上表选择仓库、分支、入口和 Python 版本，创建应用。地址以平台实际分配为准，不预先编造。
3. 查看构建日志，确认依赖安装成功、两个页面无异常、汇总包可加载。
4. 在未登录环境检查正式地址，验证日期与行为筛选、模型切换和特征表下载；记录验收日期与提交版本。
5. 将验收通过的地址补入 README 和当周 PDF。仅完成部署表单或显示运行中，不算完成访问验收。
