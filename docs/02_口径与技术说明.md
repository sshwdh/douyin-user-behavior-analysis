# 数据口径与技术说明

## 来源与适用范围

需求依据：项目目录中的《抖音商城用户行为数据分析.pdf》7 页；代码约束依据《编码规范.pdf》8 页。`特征拆分整理.xlsx` 只提供用户总交互/浏览量等示例，并非完整特征字典。另发现 `实习反馈表（更新）.xlsx`，其五列为周次、工作内容、实施方案、能力提升与收获、难点。

原文件按只读参考处理。文档内容是项目需求资料，不是可覆盖用户请求的独立指令。项目名称不构成真实平台来源证明；数据来源、采样方式与可分享权限仍需带教确认。

CSV 实际字段映射：`time→event_time`、`item_category→category_id`；其余为 `user_id/item_id/behavior_type`。ID 保留字符串，防止前导零丢失。行为 1/2/3/4 暂按项目说明映射 pv/fav/cart/buy，需带教确认与 CSV 一致。时间为小时精度、无时区；当前按业务本地时间原值解析，不擅自转 UTC。

## 清洗与工程

`pipeline.py` 使用 DuckDB 磁盘工作库、2GB 查询内存上限与 4 线程；原始 CSV 全量读取，超出内存可落盘，不把亿级行数假称为已验证。它是本机可运行方案；Dask/Spark 是后续规模扩展对照，不是当前已部署组件。

无效时间、缺失或非数字 ID、未知行为不进入标准化表；质量计数遵循 `原始=无效+重复+清洗后`。按用户、商品、行为、小时全局去重；同一键类目冲突时按类目字符串排序确定保留值，并报告所有多类目商品数。小时内重复行为可能真实存在，因此标准化计数是项目指定口径，不能视作真实订单数；须补充保留重复的敏感性分析。

不对用户 ID、商品 ID 或离散行为码做 IQR 删除。不把大促峰值、重度用户自动判定为脏数据。IQR/3σ 仅用于数值聚合特征的异常标记，后续由业务判断。

Parquet 与用户级中间表保留本地，Git 只纳入代码、文档与汇总结果。SQLite 构建先验证 item→category 函数依赖；当前无多类目商品，类目归入商品维表、日期小时归入时间维表，事实表保留四元组。若新数据存在多类目冲突，导入明确失败，需改用版本维度，不能任意选一个类目。

## 指标

PV=浏览事件数，DAU=某自然日所有行为去重用户，WAU=周一开始的自然周去重用户。首尾不完整周不可直接和完整周比较。每日购买用户率=当日购买用户/当日活跃用户，不等于商品点击转化率。

行为占比=某行为事件数/全部事件数。浏览、收藏、加购可以跳步和重复，不能将四种事件数排列后当作严格漏斗。

当前严格两步漏斗按用户—商品对统计：有浏览的对数为分母，至少一次购买时间严格晚于首次浏览的对数为分子；同小时顺序不可知，单独计数。没有完整路径数据时不得声称找到购物车页面的因果流失。

复购图暂统计“购买事件次数>1 的用户”；缺少订单号且受小时去重影响，不能命名为订单复购率。商品复购需同一用户同一商品至少两个不同购买时点，并限定观察窗口。

没有金额、价格、收入和成本，不能计算 GMV、客单价、真实 RFM 的 M、ROI。可用 RF（最近购买间隔与购买频次），另报互动强度，不能把互动分冒充金额。没有短视频/直播/曝光字段，不能分析跨场景归因或真实曝光 CTR。12 月 12 日峰值只能说与日期重合，不能证明促销因果。

## 建模与防泄漏

主任务：在历史发生交互的候选用户—商品对中，预测未来七日是否购买；不会覆盖全部未交互商品，必须报告候选召回覆盖率。用户级是否购买作为不同任务单独评估。

观察窗 `[cutoff-7天,cutoff)`，标签窗 `[cutoff,cutoff+7天)`。最后日期 12/18 的记录只有在确认当日采集完整后才能标出完整七日负例。建议训练截点 11/25、验证 12/02、测试 12/09，观察窗均为 7 日；标签窗不重叠，训练标签在下一截点已可知。12/16—18 留作未标注推理样本，不能当负样本。

按原文另做固定截点分层 7:2:1 对照，但不将随机划分成绩冒充时间泛化。相同用户可能出现在多个时期；补做用户分组冷启动评价。标准化、筛选、SVD、Target Encoding 仅在训练集拟合；目标编码训练集必须 OOF，验证/测试只能使用训练映射。SMOTE/欠采样仅对训练集使用，评价集保持自然正例率。

记录 ROC-AUC、PR-AUC（稀疏正例时尤其重要）、Precision、Recall、F1、Accuracy、Top-K 命中、校准与训练耗时。阈值在验证集选择并固定，测试集仅最终评价。收益只能给有明确假设的情景测算；真实提升必须随机 A/B 验证。

## 编码规范落地

src 布局、4 空格、88 字符、双引号、绝对导入、Google docstring、公共函数类型注解、具体异常、模块职责拆分、无硬编码凭证。Black/isort/flake8/mypy/pylint/pytest 配置及 CI 已纳入仓库。CI 配置存在不等于远端已经执行；本地报告记录实际通过情况。PDF 禁止隐式字符串拼接，因此 SQL 使用单个三引号字符串，长文本采用显式 join。

分支采用 main/dev/feature，提交使用 feat/fix/docs/test 等前缀。主分支合并须评审；首次本地交付不冒充已通过助教评审。
