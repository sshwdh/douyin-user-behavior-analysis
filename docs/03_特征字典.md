# 特征字典与实现状态

所有预测特征均只计算截点之前的历史。当前流水线的 user_summary/item_summary 是全窗口 EDA 中间表，禁止直接喂入未来预测。下表为可执行开发定义，未标已实现的均待实现。

| 层级 | 字段 | 定义 | 处理 | 状态 |
|---|---|---|---|---|

| 用户 | distinct_items | 全窗口商品去重数 | EDA only | 已实现 |
| 用户 | active_days | 全窗口活跃自然日数 | EDA only | 已实现 |
| 用户 | last_active | 全窗口最后行为时间 | EDA only | 已实现 |
| 商品 | events/users | 全窗口交互数/去重用户 | EDA only | 已实现 |
| 用户 | user_event_count_7d | 观察窗事件数 | log1p+标准化 | 待实现 |
| 用户 | user_pv/fav/cart/buy_7d | 各行为事件数 | log1p | 待实现 |
| 用户 | user_active_days_7d | 观察窗活跃日数 | 标准化 | 待实现 |
| 用户 | user_recency_hours | 截点减最后行为 | 标准化；新用户另标记 | 待实现 |
